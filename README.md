### TWRP device tree for POCO M6 5G (air)
=========================================

The POCO M6 5G (codenamed _"air"_) is a low-end, budget smartphone from Xiaomi.

It was released in December 26, 2023.

## Device specifications

Basic   |    Spec Sheet
-------:|:-------------------------
CPU    |  Octa-core (2x2.2 GHz Cortex-A76 & 6x2.0 GHz Cortex-A55)	
Chipset |  Mediatek Dimensity 6100+
GPU    |  Mali-G57 MC2
Memory |	4GB/6GB RAM (LPDDR4x)	
Shipped Android Version | Android 13, MIUI 14
Storage |	64GB/128GB (UFS 2.2)	
Battery |	Non-removable Li-Po 5000 mAh battery	
Display |	720 x 1600 pixels, 6.74 inches, 90 Hz, IPS-LCD
